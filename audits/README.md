# audits/

Your client work goes here, one folder per client per date. Everything in this folder is ignored by git except this README and `_template/`.

The agent creates `audits/<client>/<YYYY-MM-DD>/` from `_template/` when you start an audit. Save each file's accounts-only XML export into that folder's `xml/` subfolder.

Don't commit anything from here, and keep finished audits in your firm's secure client storage.
